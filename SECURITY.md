# Güvenlik / Security

Bir güvenlik açığı bulduysan lütfen herkese açık bir issue açma. GitHub'da bu deponun
**Security** sekmesinden **Report a vulnerability** ile özel olarak bildir. Bildirimde etkilenen
sürümü (`git describe`), yeniden üretme adımlarını ve olası etkisini yaz.

Please do not open a public issue for a security problem. Report it privately through this
repository's **Security** tab (**Report a vulnerability**) on GitHub, with the affected version
(`git describe`), steps to reproduce and the likely impact.

Desteklenen sürüm yalnızca `main` dalının son hâlidir. / Only the latest `main` is supported.
